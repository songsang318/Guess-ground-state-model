# Guess-ground-state-model

개요 : 해밀토니안을 입력받아 바닥 상태와 바닥 상태 에너지를 출력하는 인공신경망 모델 제작이 목표이다.
- 해밀토니안은 T + V 의 형태로 나타나는데, T는 고정적이므로 V만을 input vector로 입력받는다.
- 신경망을 지나 output vector를 출력한다.
- 바닥상태는 감쇠지수함수 * 푸리에급수 형태로 가정하고, output vector를 순서대로 감쇠지수계수, 푸리에급수의 계수들로 사용한다.

/ 로스 설계
- 우선 가장 신경망의 정의에 부합하는 손실함수는 "E_gs - E_pred" 이다.
- 그러나 E_gs를 구하는 것이 어렵고, 학습 데이터가 한정된다.
- 따라서 ritz의 변분 원리를 근거로, 에너지 고윳값을 로스함수로 사용하여, 이를 최소화하는 방향으로 gradient descent를 진행한다.
- 그러나 각 해밀토니안마다 에너지 고윳값이 다르기 때문에, 로스가 잘 정돈되지 않는 문제가 있다.
- 따라서 슈뢰딩거 방정식의 잔차 (Hpsi - Epsi) 를 L1으로 E를 L2 로 삼고 loss = L1 + w * L2 로 설계하였다.
- 9/15일 기준 잘 안되고 있다.

/ 현재 진행 상황
- 9/15 : 
> output vector size = 11 (코사인 기저 5개, 사인 기저 5개, 감쇠지수항 1개)
> activation ftn = tanh
> model size = 128 -> 64 -> 32 
> w = 0.01
> loss 가 5 근처에서 떨어지지 않는다. 파라미터 조정을 통해 더 적은 에포크(3~400)에서 빨리 도달할 수 있게는 되었지만, 로스가 5보다 더 떨어지는 일은 없다.
> w를 작게 설정했기 때문에 사실상 L1이 5 수준이라는 것인데, 미분방정식의 잔차라기에는 값이 너무 크다.
> 계획 : 우선 불명확한 로스 설계만으로 쇼부치려는 생각은 접고, 정석적인 로스함수 (E_gs - E_pred) 를 사용한 모델을 한 번 만들어 봐야겠다.
